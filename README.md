# JavaScript Learning Lab

Hands-on JavaScript tutorial repository divided into **Beginner**, **Intermediate**, and **Advanced** levels.

**Last updated:** October 1, 2026

Each lesson contains:
- Clear explanation
- Runnable example code
- Practice exercises
- Corresponding unit tests (in `/tests`)

## Structure

```
javascript-learning-lab/
├── beginner/          # Fundamentals
├── intermediate/      # Intermediate concepts
├── advanced/          # Advanced topics
├── exercises/         # Extra practice exercises
├── tests/             # Unit tests
└── projects/          # Small complete projects
```

## How to use

1. Clone the repository
2. Make sure you have Node.js 18+ installed
3. Go into any lesson folder and run the file with Node

```bash
git clone https://github.com/dureen/javascript-learning-lab.git
cd javascript-learning-lab

# Example: run a beginner lesson
node beginner/01-hello-world/main.js
```

## Requirements

- Node.js 18 or higher
